1. 三分钟上手

  1. 把压缩包用 7-Zip 完整解压到短路径（推荐 ***REMOVED***）。
    不要用系统自带的解压功能，也不要解压到很深的目录。
  2. 双击包根目录下的 ***REMOVED******REMOVED***，会弹出桌面控制面板。
  3. 面板会自动启动服务（约 1~2 秒），状态变为 ● 运行中 后浏览器自动打开工作台页面。
  4. 关闭面板窗口不会停止服务。要彻底停止，请点面板上的「停止服务」。
首次使用建议先点一次「换机自检」：它会检查组件完整性、写权限、端口占用、C 盘外写情况，并给出本机的速度预期，比事后排查省事得多。

3. 功能一：PPT 生成

工作台地址默认 http://***REMOVED***:***REMOVED***（端口被占用时会自动顺延，以面板显示的为准）。

基本流程

  1. 在模板库中选择一个模板（首次运行会自动生成一个示例模板）。
  2. 把大纲或原始素材粘进输入框，也可以上传参考图让视觉模型解读版面。
  3. 点「AI 生成大纲」让本地模型整理结构，不满意可以再点「润色」。
  4. 点「生成 PPT」，完成后可在线预览、下载，并附带一份质量自检报告。

模板怎么加

把公司的 .pptx 直接复制到 templates_library\ 目录，回到页面点刷新即可。工具会读取模板的版式、字体与配色并沿用。

4. 功能二：文献速读与脑图

地址默认 http://***REMOVED***:***REMOVED***，也可从面板点「打开文献脑图」直接进入。

用法

  1. 一次上传 3~5 篇（上限 6 篇；超出后会自动淘汰最旧的，避免测试残留占位）。
  2. 点「开始分析」，页面会显示分阶段进度与预计剩余时间。
  3. 产出包含：逐篇结构化精读、跨文献综合评述、定量对比矩阵、研究方向与专利设计建议、可交互思维导图。
  4. 可导出 Markdown 综述、JSON 结果与脑图数据。

支持的文献格式

格式说明
.pdf主用格式。正文由随包分发的 pypdf 6.18.0 解析（纯 Python、无外部依赖，比旧解析器完整度高、不丢正文）
.txt / .md / .markdown纯文本，直接读取
扫描版（图片型）PDF 没有文本层，解析结果会是空的。 判断方法：用鼠标在正文上拖一下，如果选不中文字，就是扫描版。 这类文件需要先用 OCR 处理成带文本层的 PDF，或把正文粘贴成 .txt 再上传。 这是 PDF 格式本身的限制，不是工具故障。

关于数值可信度

工具采用三层校验：只允许填写原文真实出现过的数值 → 逐条回原文检索标记是否命中 → 对比矩阵逐格标注是否已核验。 未能在原文中定位到的数值会明确标注「未核验」，请以原文为准。

一次放 3~4 篇最划算。跨文献综述是固定成本（约占全流程 40%），分成多次单篇跑会把这份成本重复付好几遍。

5. 换机部署四步

  1. 解压：用 7-Zip 解压到短路径，例如 ***REMOVED***。目标盘预留 10 GiB 以上空间。
  2. 自检：双击 ***REMOVED******REMOVED*** → 点「换机自检」，逐项确认没有红色提示。
  3. 启动：在面板点「启动工作台」。若状态一直是「未运行」，看面板日志区的最后几行。
  4. 收尾：用完点「停止服务」，避免 ***REMOVED*** 长时间占用内存。

如果 exe 双击没反应 / 被拦截

目标机如果装了带「可执行文件管控」的终端安全软件，可能会静默拦掉 ***REMOVED***。两个办法，任选其一：

  • 在包根目录执行一次 powershell -NoProfile -Command "Get-ChildItem -Recurse | Unblock-File"，然后重试。
  • 改用 ***REMOVED*** 启动——它会自动走包内 ***REMOVED*** 运行时，功能和面板完全一样，只是没有图形界面（用 stop.bat 停止）。

不需要的东西

  • 不需要管理员权限、不需要装 Python、不需要联网下载任何组件。
  • 不需要改注册表、不改 PATH、不注册系统服务、不写入 Program Files。
  • 拷到 U 盘或移动硬盘同样可用（建议用较快的盘，慢盘会影响模型加载速度）。

如果被 SmartScreen 拦住

从别的机器拷贝过来的文件可能带「来自其他计算机」标记。在包根目录执行一次下面的命令即可解除（不需要管理员）：

powershell -NoProfile -Command "Get-ChildItem -Recurse | Unblock-File"

7. 常见问题排查

双击 exe 没有任何反应

  • 确认是完整解压而非直接在压缩包里双击——压缩包内双击只会解压出 exe，缺 ***REMOVED***\ 无法运行。
  • 确认解压目录不是只读，也没有被杀软实时隔离。
  • 如果是从别的电脑拷来的，先跑一次 Unblock-File（见下一节）。

exe 被安全软件拦了 / 文件不见了

  • 先确认根目录下 ***REMOVED******REMOVED*** 与 ***REMOVED***\ 都还在；被杀软隔离时 ***REMOVED***\ 往往也被一起删掉。
  • 把整个目录加入杀软白名单后重新解压。
  • 临时应急：直接双击 ***REMOVED***，它会用包内 ***REMOVED*** 把服务跑起来，不依赖任何 exe。

面板显示「未运行」

  • 看面板日志区的最后几行，那里有真实原因。
  • 若提示端口占用，直接点「停止服务」再重新「启动工作台」；端口会自动顺延。
  • 若提示缺少组件，说明解压不完整或路径过长，换短路径重新解压。

浏览器打不开页面，但面板显示「运行中」

  • 最常见原因：系统代理没有排除 ***REMOVED***。关掉系统代理，或在代理绕过列表中加入 ***REMOVED***;***REMOVED***。
  • 手动把面板上显示的真实地址复制到浏览器（端口可能已顺延，不是 ***REMOVED***）。

生成 PPT 时每次都要等很久

  • 检查 ***REMOVED*** 里的 ***REMOVED***_keep_alive 是否为 "30m"。设为 0 会导致每次调用都重新加载模型。

文献脑图页面空白

  • 多半是 ***REMOVED***\code\literature_tool\static\vendor\d3.v7.min.js 缺失，说明包解压不完整，请重新完整解压。

日志在哪里

  • ***REMOVED***logs\ 下有 launcher.log、workbench.log、literature.log、***REMOVED***.log。

9. 扫描版 PDF 与 OCR

期刊的早年卷期、会议扫描件、专利与内部报告常常只有图像、没有文本层，直接提取会是空的。本工具随包带了 ***REMOVED***.5.3，自动处理这类 PDF——不需要你手动切换模式，也不需要额外装任何东西。

它是怎么判断的

按每页的文本层密度判断，而不是看文本总量。这一点很关键：像「封面有文字层、正文全是扫描图」这种混合件，只看总量会被误判成正常 PDF，结果是静默地只返回封面那一页的文字——比"解析为空"更难发现。

  • engine = pypdf：正常文字版 PDF，用文本层（最快最准）。
  • engine = ocr(tesseract)：扫描版／混合件，无文本层的页走 OCR。

混合件是逐页择优的：本来就有文本层的页直接用原文（比 OCR 准），只有图像页才 OCR，最后合并。上传后文件列表会显示 OCR 徽标，鼠标悬停可看识别语种。

速度

200 dpi 下约 1.4 秒/页（本机 GPU 机型实测），单篇默认最多识别 25 页（***REMOVED*** 的 ***REMOVED*** 可调）。第一次识别某篇会写入 ***REMOVED***ocr_cache\，同一篇再上传是毫秒级。

栅格化后端（判断是否降级）

OCR 前要把 PDF 每页渲染成位图，这一步由 pypdfium2（PDFium，Chrome 同款内核）完成。若它不可用，程序会降级为只抽取页面里已嵌入的位图——扫描件通常仍然能识别，但混排页面可能漏内容。

为了让降级可见而不是静默发生，上传响应里带了 ocr_raster 字段：pdfium 为正常，pypdf-embedded 为降级。***REMOVED***（换机自检.bat）里也会直接显示「OCR 栅格化后端」与 pypdfium2_cfg 的存在与否。正常安装下应看到 pdfium。

语种（已随包带中英文）

随包带英文（eng）与简体中文（chi_sim）两个语言包，中英文文献都能直接识别，无需任何配置。

要再加别的语种（如日文 jpn、德文 deu），把对应的 *.***REMOVED*** 放进 ***REMOVED***tesseract\***REMOVED***\ 即可，不需要改代码、不需要改配置——引擎按 eng → chi_sim → jpn → deu → fra 的顺序自动挑当前可用的那个。***REMOVED*** 里能看到当前实际可用的语种。

中文识别结果会自动去掉汉字之间被 OCR 加上的逐字空格（阈 值 电 压 → 阈值电压），否则按关键词检索会全部失配、送进大模型的上下文也会多出成倍噪声。汉字与数字/英文之间的空格会保留（28 nm、pMOS 器件 不能被粘起来）。

***REMOVED*** 的 ocr 段可以调 dpi（默认 200；300 更慢但没有精度收益）、psm（默认 3，对双栏论文最稳）、lang（留空 = 自动）。

如果包解压在中文路径下

***REMOVED***.x 在 Windows 上遇到非 ASCII 路径会直接报 Illegal byte sequence，而且它的 --version 不会有任何异常——这个坑很容易漏。本工具做了三级自动规避，你不需要手动处理：

  1. 原地使用：路径本来就是纯英文，直接用。
  2. 8.3 短名：用 Windows 短名换取 ASCII 路径，零拷贝。
  3. 暂存副本：把引擎复制到纯英文目录。落点优先工具包自己所在的盘（如 ***REMOVED***），不会默认写 C 盘。

同时，因为启动器会把临时目录重定向到包内（做到零 C 盘落盘），包路径含中文时临时目录也会带中文，工具会自动把它一并切到 ASCII 目录——否则 Tesseract 连栅格图都读不进去。

如果 ***REMOVED*** 显示「已暂存到 ASCII 目录」，说明确实走了第 3 级，在包所在盘根目录生成了一个 PWB_OCR\（约 108 MB）。它可以直接删，下次运行会按需重建。想避免这一步，把包解压到纯英文路径是最省事的做法。

10. 版权与代码保护

授权范围

本工具是授权范围内的内部工具，著作权归权利人所有。许可与禁止条款见包根 ***REMOVED***；第三方开源组件的许可与致谢见 ***REMOVED***。在命令行敲 ***REMOVED***-cli***REMOVED*** ***REMOVED***，或点面板上的「关于 / 版权」，可以随时查看。

业务代码是密文，磁盘上找不到源码

包内不存在任何可直接阅读的 Python 业务源码：业务逻辑以 .pwbx 密文随包分发，运行时在内存中解密后执行。运行期也不会产生 .pyc 或 __pycache__。你在 ***REMOVED***\code\ 下能看到的只有 .pwbx 与 static\ 静态资源。

改过就会被发现

核心文件的 ***REMOVED*** 记录在 ***REMOVED***\***REMOVED***.json 里：

  • 启动时自动校验（毫秒级）；
  • 密文被改动 → 该模块直接拒绝运行，并提示"重新用 7-Zip 完整解压"；
  • ***REMOVED***-cli***REMOVED*** ***REMOVED*** 会报「被改动 N 个文件」并以非零码退出。

这不是"防你自己"，而是防误触：用非 7-Zip 的解压工具、或手工改包内文件，都会导致程序行为不可预期——提前报错比事后玄学排查好。
