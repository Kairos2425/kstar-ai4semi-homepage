2. 累积失效分布函数 CDF：F(t) 与 R(t)

CDF 表示器件寿命 T 不超过时间 t 的概率：F(t)=P(T≤t)。可靠度为 R(t)=P(T>t)=1-F(t)。

F(t)=P(T≤t)　　　R(t)=1-F(t)
-累计失效概率 F(t)
-可靠度 R(t)
-校验：F(t)+R(t)
-结果解释
风险提示：CDF 是累计概率，不是瞬时失效率；若图线下降、概率小于 0 或大于 1，就说明计算或输入有问题。

3. 经验 CDF 与 CDF 图：从失效时间到曲线

经验 CDF 将失效时间排序后，为每个失效点分配累计失效概率。简单演示可用 i/n 或中位秩近似 (i-0.3)/(n+0.4)。

-方案 A 在目标时间前失效比例

图表读法：同一时间下 CDF 越低，表示累计失效比例越低，可靠性越好；同一失效比例下，所需时间越长，寿命表现越好。

4. 正态分布：参数波动与规格限风险

正态分布适合描述围绕均值对称波动的连续变量，如阈值电压、尺寸误差、测量噪声等。寿命数据通常非负且右偏，不宜默认正态。

-P(X<LSL)
-P(X>USL)
-规格内概率
-学习反馈
误区：正态分布理论上允许负值，因此不能不加判断地套到非负寿命数据上。

5. 对数正态 Lognormal 分布：正值右偏寿命

若 Y=ln(T) 近似服从正态分布，则 T 服从对数正态分布。它适合正值、右偏、受多个乘法因素影响的寿命数据。

-F(t)
-R(t)
-中位寿命 exp(μ)
-结果解释
风险提示：对数正态要求寿命 T>0；对数均值反变换通常对应原始尺度中位数，不是原始均值。

6. Weibull 分布：寿命分析与失效率趋势

二参数 Weibull 的 CDF 为 F(t)=1-exp[-(t/η)^β]。β 是形状参数，η 是尺度参数。

F(t)=1-exp[-(t/η)^β]　　　R(t)=exp[-(t/η)^β]
-F(t)
-R(t)
-B10 寿命
-β 含义
误区：η 对应约 63.2% 累计失效位置，不等于平均寿命；混合失效模式后强行拟合单一 Weibull 会让参数失去工程意义。

7. CDF 图与概率图的分布识别

概率图通过坐标变换将特定分布线性化。若数据点在某类概率图上更接近直线，说明该分布可能较合理，但仍需结合失效机理和样本量。

正态概率图

横轴为数据值，纵轴为正态分位变换后的累计概率。适合对称型变量。

Lognormal 概率图

横轴常用 ln(t)，若点接近直线，说明对数尺度下近似正态。

Weibull 概率图

常用 ln(t) 与 ln[-ln(1-F)] 作图，斜率可关联 β。

8. 最小二乘法：从散点到拟合线

最小二乘法通过最小化残差平方和来估计模型参数。它是拟合工具，不是可靠性分布本身。

min Σ(yᵢ-ŷᵢ)²　　　线性模型：y=a+b x
-拟合参数
-残差平方和 SSE
-R²
-学习反馈
风险提示：高 R² 不代表模型物理正确；异常值会显著影响普通最小二乘拟合。

9. 插值法：观测范围内估算

插值用于估算已有数据点之间的值。线性插值公式为：y=y1+(y2-y1)(x-x1)/(x2-x1)。

y = y1 + (y2-y1) × (x-x1)/(x2-x1)

-插值/外推判断
-结果解释
误区：当目标点超出已知数据范围时，已经不再是插值，而是外推，风险明显增加。

10. 退化趋势外推：从短期测试预测阈值寿命

退化趋势外推适合“还没等到大量失效，但性能参数已经随时间变化”的场景。关键是退化指标必须与失效阈值有明确工程关系。

-预测阈值寿命
-模型参数
-外推距离
-风险解释
重要提示：外推结果是模型预测，不是实测寿命；外推越远，越需要更长时间验证、置信区间和物理机理支撑。

案例 B：退化数据分析流程

  1. 绘制时间-性能退化散点。
  2. 用最小二乘拟合退化趋势。
  3. 在测试范围内插值读取中间值。
  4. 在测试范围外外推到阈值。
  5. 输出寿命预测与风险说明。

本案例由第 8、9、10 章的交互模块共同完成。建议学习时先调整最小二乘异常点，再观察插值和退化外推结论如何变化。

综合结论模板：在当前模型和阈值假设下，预测寿命为 X 小时；若 X 超出实测区间很多，应标注为高不确定性外推。

12. 常见误区与检查清单

常见误区为什么有问题建议做法
把插值当外推超出观测范围后模型不确定性急剧增加明确目标点是否在数据范围内
只看 R²拟合好不代表机理正确，也不代表外推可靠检查残差、异常值、物理意义和样本量
寿命数据默认正态寿命非负且常右偏，正态可能给出负寿命优先检查 Weibull 或 Lognormal
删除未失效样品未失效样品携带右删失信息，删除会造成偏差标注删失状态并采用合适方法处理
混合失效模式单一分布参数失去工程解释先做失效分析，再分模式建模
只报告平均寿命可靠性常关注低分位早期失效报告 B10、CDF、可靠度和置信区间
